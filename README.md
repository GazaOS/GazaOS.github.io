# GazaOS Official Website

Official portal, interactive UI showcase, and OTA download hub for **GazaOS** (Android 16.2 / Baklava).

- **Website**: https://gazaos.github.io
- **Organization**: https://github.com/GazaOS
- **Pages**:
  - `index.html` — Project overview, interactive **GazaOS Hybrid / HyperOS / ColorOS / AOSP** UI Studio, Modular Quick Settings & About Phone preview, and Palestine solidarity resources
  - `devices.html` — Searchable device download portal hydrated from `devices/<codename>/<codename>.json`
  - `team.html` — Core developers and device maintainers
- **Supported Devices**: Xiaomi Redmi Note 12 5G / POCO X5 5G (`stone` / `sunstone` / `moonstone`)
