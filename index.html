Security & Firewall

November 2026 security patch, SELinux enforcing rules, and built-in Datura firewall for per-app network control.

Lean Footprint

Heavy add-ons remain opt-in (`TARGET_INCLUDE_* ?= false`), keeping Vanilla images around 1.3 GB with `speed-profile` dexopt.

Audio Stack

Includes ViPER4Android FX and Sony Dolby Atmos alongside lightweight HyperOS 4 notification and UI sounds.

Open Source

Platform trees, OTA manifests (`GazaOS/OTA`), changelogs, and issue tracking are open and verifiable on GitHub.

Build from Source

Standard manifest workflow

Initialize and sync the GazaOS 16.2 tree cleanly from github.com/GazaOS/android:

# Sync platform repositories
repo init -u https://github.com/GazaOS/android -b 16.2 --git-lfs
repo sync -c -j$(nproc --all) --force-sync --no-tags

# Build Official Vanilla
export GAZAOS_BUILD_TYPE=OFFICIAL WITH_GMS=false
source build/envsetup.sh && lunch lineage_stone-bp4a-user && m bacon
