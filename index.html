02 • Longevity & Open Engineering

Open source from manifest to device trees

Every GazaOS core repository (`frameworks_base`, `build_soong`, `build_make`, `vendor_lineage`, `Settings`, `Singularity`, `Launcher3`, `Updater`, `SetupWizard`) is public on github.com/GazaOS. Sync the source tree and build cleanly:

# Initialize GazaOS 16.2 manifest
repo init -u https://github.com/GazaOS/android -b 16.2 --git-lfs
repo sync -c -j$(nproc --all) --force-sync --no-tags

# Configure & build Official Vanilla
export GAZAOS_BUILD_TYPE=OFFICIAL WITH_GMS=false
source build/envsetup.sh && lunch lineage_stone-bp4a-user && m bacon
